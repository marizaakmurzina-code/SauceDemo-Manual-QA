# SauceDemo — Manual QA Testing Portfolio

## About the Project

This is an independent Manual QA practice project focused on testing the SauceDemo e-commerce web application.

The project demonstrates test case design, functional testing, negative testing, exploratory testing, and test documentation skills.

**Application under test:** https://www.saucedemo.com/

## Testing Scope

- Login and logout
- Product catalog and sorting
- Shopping cart
- Checkout form validation
- Order completion

## Testing Techniques

- Positive and Negative Testing
- Equivalence Partitioning
- Exploratory Testing
- Functional Testing

## Tools

- Google Chrome
- Chrome DevTools
- Google Sheets / Microsoft Excel
- GitHub

## Project Documentation

- `Test_Plan.md` — testing objectives, scope, and approach
- `Test_Cases.csv` — test scenarios and execution results
- `Checklist.md` — functional testing checklist
- `Test_Summary.md` — testing results and conclusions
- `Bug_Reports/` — documented confirmed defects
- `Screenshots/` — test evidence
