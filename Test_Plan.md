# Test Plan — SauceDemo

## 1. Project Overview

**Application:** SauceDemo (Swag Labs)  
**Website:** https://www.saucedemo.com/  
**Testing Type:** Manual Functional Testing  
**Environment:** Google Chrome on Windows  
**Tester:** Mariza Akmurzina

## 2. Testing Objectives

The objective of this project is to verify the main user workflows of the SauceDemo e-commerce application and document testing results.

## 3. Scope of Testing

The following features will be tested:

- User login and logout
- Product listing
- Product sorting
- Adding and removing products from the shopping cart
- Shopping cart functionality
- Checkout form validation
- Order completion

## 4. Testing Techniques

- Positive Testing
- Negative Testing
- Equivalence Partitioning
- Boundary Value Analysis where applicable
- Exploratory Testing
- Functional Testing

## 5. Test Environment

- Browser: Google Chrome
- Operating System: Windows
- Application: SauceDemo
- Testing Tools: Chrome DevTools, Google Sheets / Excel

## 6. Entry Criteria

- The website is accessible.
- Test accounts are available.
- Test cases are prepared.

## 7. Exit Criteria

- Planned test cases have been executed.
- Actual results have been documented.
- Confirmed defects have been recorded.
- A final test summary has been prepared.

## 8. Limitations

This is an independent educational testing project. It is based on observed application behavior and exploratory test scenarios, not internal Sauce Labs product requirements.

Performance testing, security penetration testing, backend database testing, and production payment verification are outside the scope.
