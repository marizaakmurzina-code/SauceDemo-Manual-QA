# SauceDemo Manual Testing Checklist

## Login

- [ ] Login with valid credentials
- [ ] Login with an incorrect password
- [ ] Login with an incorrect username
- [ ] Login with empty username
- [ ] Login with empty password
- [ ] Login with both fields empty
- [ ] Login with a locked-out user
- [ ] Logout from the application

## Products

- [ ] Product names are displayed
- [ ] Product images are displayed
- [ ] Product prices are displayed
- [ ] Sort products by price: low to high
- [ ] Sort products by price: high to low
- [ ] Sort products by name: A to Z
- [ ] Sort products by name: Z to A

## Shopping Cart

- [ ] Add one product to the cart
- [ ] Add multiple products to the cart
- [ ] Remove a product from the cart
- [ ] Verify cart quantity
- [ ] Continue shopping from the cart
- [ ] Navigate to checkout

## Checkout

- [ ] Complete checkout with valid information
- [ ] Submit checkout with an empty first name
- [ ] Submit checkout with an empty last name
- [ ] Submit checkout with an empty postal code
- [ ] Verify order summary and totals
- [ ] Complete an order successfully
- [ ] Return to products after order completion

## Test Documentation

- [ ] Actual results recorded
- [ ] Test execution statuses updated
- [ ] Screenshots captured where useful
- [ ] Confirmed bugs documented
- [ ] Test summary completed
